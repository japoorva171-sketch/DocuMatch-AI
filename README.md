# DocuMatch AI

## Project Overview
DocuMatch AI is an AI-powered business document reconciliation application.

## Problem Statement
Businesses manually compare purchase orders, invoices and delivery notes. This takes time and can lead to errors.

## Objectives
- Extract information from business documents.
- Compare purchase orders and invoices.
- Detect quantity and price mismatches.
- Identify missing documents.
- Generate supplier clarification emails.

## Technology Stack
- Python
- Streamlit
- PyMuPDF
- LLM API
- Git and GitHub

## Project Workflow
Upload → Extract → Match → Validate → Explain → Draft Email

## Team Responsibilities
- Developer 1: AI and document processing.
- Developer 2: Validation and user interface.
